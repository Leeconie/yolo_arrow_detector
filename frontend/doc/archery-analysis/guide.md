# 射箭分析结果模块开发文档

## 一、模块概述

### 1.1 功能描述

射箭分析结果模块负责实现射箭视频分析结果的可视化展示，包括靶纸绘制、命中点标记、环数标注、结果列表展示和排序功能。

### 1.2 适用场景

- 射箭视频分析结果展示
- 命中点可视化
- 结果统计和排序

### 1.3 技术栈版本

- **fabric.js**: 5.3.0
- **Element Plus**: 2.13.0

## 二、目录结构

本模块创建的目录和文件：

```text
src/modules/analysis/archery/
├── composables/
│   └── useArcheryRender.ts     # 射箭分析渲染组合式函数
└── utils/
    └── targetUtil.ts           # 靶纸绘制工具函数
```

## 三、技术实现

### 3.1 靶纸绘制

- 使用fabric.js绘制同心圆
- 共10环，环数从内到外10-1
- 颜色交替（红/白）

### 3.2 命中点渲染

- Circle对象，radius=5，颜色#FF0000
- 位置对应frameData.data.hitPoint.x/y

### 3.3 环数标注

- Text对象，字体大小24，颜色#FF0000
- 位置在命中点右侧10px处

### 3.4 结果列表

- 使用Table组件展示
- 列字段：帧编号、命中时间、环数、命中位置
- 支持按环数/时间排序

## 四、接口定义

### 4.1 结果汇总接口

- **GET** `/api/analysis/archerySummary?videoId=<videoId>`
- 响应：射箭结果汇总列表

## 五、组件说明

本模块主要提供工具函数，结果列表组件将在result-page模块中实现。

## 六、开发要点

1. 命中点坐标需转换为Canvas坐标体系
2. 靶纸圆心位于Canvas中心
3. 结果排序需支持多字段排序

## 七、测试要求

- 单元测试：测试靶纸绘制、命中点渲染逻辑
- 集成测试：测试结果列表排序功能

## 八、依赖关系

- 依赖core模块：使用analysisStore、类型定义
- 依赖video-player模块：使用Canvas画布
