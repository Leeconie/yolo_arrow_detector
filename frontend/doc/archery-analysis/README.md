# 射箭分析模块

## 模块概述

射箭分析结果模块负责实现射箭视频分析结果的可视化展示，包括靶纸绘制、命中点标记、环数标注、结果列表展示和排序功能。

## 模块职责

- 靶纸绘制（使用fabric.js绘制同心圆）
- 命中点标记和环数标注
- 结果列表展示和排序
- 射箭分析摘要获取
