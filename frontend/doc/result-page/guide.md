# 结果展示页面模块开发文档

## 一、模块概述

### 1.1 功能描述

结果展示页面模块整合各分析模块，实现ResultPage页面。页面包含视频回放区、结果展示区（根据视频类型显示不同内容）、结果统计、导出功能等。

### 1.2 适用场景

- 分析结果可视化展示
- 结果统计和排序
- 结果导出

### 1.3 技术栈版本

- **Vue**: 3.5.26
- **Element Plus**: 2.13.0
- **fabric.js**: 5.3.0

## 二、目录结构

本模块创建的目录和文件：

```text
src/modules/video/result/
└── page/
    └── ResultPage.vue          # 结果展示页面
```

## 三、技术实现

### 3.1 页面布局

- 左侧：视频回放区（60%宽度）
- 右侧：结果展示区（35%宽度）
- 底部：重新分析按钮、导出结果按钮

### 3.2 结果展示区

- 人体视频：显示关键点统计、手部关键点详情列表
- 射箭视频：显示射箭结果汇总表格、统计信息

### 3.3 结果联动

- 点击列表项，播放器跳转至对应帧
- 高亮对应分析结果

### 3.4 导出功能

- 调用/analysis/export接口
- 导出分析结果为JSON格式

## 四、接口定义

### 4.1 导出接口

- **GET** `/api/analysis/export?videoId=<videoId>`
- 响应：文件流

## 五、组件说明

### 5.1 ResultPage.vue

**Props**: 无

**路由参数**:

- `videoId`: string - 视频ID（从路由query获取）

**功能**: 结果展示主页面

## 六、开发要点

1. 页面需根据videoType显示不同的结果内容
2. 结果列表需支持排序功能
3. 导出功能需处理文件下载

## 七、测试要求

- 集成测试：测试结果展示、排序、导出功能
- E2E测试：测试完整结果查看流程

## 八、依赖关系

- 依赖core模块：使用所有Store、类型定义
- 依赖theme-switch模块：使用主题切换功能
- 依赖video-upload模块：使用videoId参数
- 依赖video-player模块：使用视频播放器
- 依赖human-pose-render模块：使用人体姿态渲染
- 依赖archery-analysis模块：使用射箭分析结果
