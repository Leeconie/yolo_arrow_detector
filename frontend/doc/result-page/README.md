# 结果展示页面模块

## 模块概述

结果展示页面模块整合各分析模块，实现ResultPage页面。页面包含视频回放区、结果展示区（根据视频类型显示不同内容）、结果统计、导出功能等。

## 模块职责

- 分析结果可视化展示
- 结果统计和排序
- 结果导出
- 结果联动（点击列表项跳转对应帧）
