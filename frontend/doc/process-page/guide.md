# 分析过程页面模块开发文档

## 一、模块概述

### 1.1 功能描述

分析过程页面模块整合视频播放、人体姿态渲染等功能，实现ProcessPage页面。页面包含视频播放器、Canvas画布、播放控制栏、关键帧时间轴、功能控制区等元素。

### 1.2 适用场景

- 视频分析过程展示
- 实时查看分析结果
- 控制分析结果渲染

### 1.3 技术栈版本

- **Vue**: 3.5.26
- **Element Plus**: 2.13.0
- **vue3-video-play**: 2.0.0
- **fabric.js**: 5.3.0

## 二、目录结构

本模块创建的目录和文件：

```text
src/modules/video/process/
└── page/
    └── ProcessPage.vue         # 分析过程页面
```

## 三、技术实现

### 3.1 页面布局

- 顶部：标题、主题切换按钮、返回按钮
- 核心区域：视频播放容器、播放控制栏、关键帧时间轴、功能控制区
- 底部：分析状态提示、查看详细结果按钮

### 3.2 视频播放容器

- 视频播放器与Canvas叠加
- Canvas层级高于视频
- 尺寸同步

### 3.3 功能控制区

- 骨架显隐切换按钮（仅人体视频显示）
- 单手/双手切换按钮（仅人体视频显示）

## 四、接口定义

本模块不直接调用API，通过组合其他模块实现功能。

## 五、组件说明

### 5.1 ProcessPage.vue

**Props**: 无

**路由参数**:

- `videoId`: string - 视频ID（从路由query获取）

**功能**: 分析过程展示主页面

## 六、开发要点

1. 页面需根据videoType显示不同的功能控制区
2. 视频播放与Canvas渲染需同步
3. 关键帧时间轴需支持横向滚动

## 七、测试要求

- 集成测试：测试页面完整功能流程
- E2E测试：测试用户交互流程

## 八、依赖关系

- 依赖core模块：使用所有Store、类型定义
- 依赖theme-switch模块：使用主题切换功能
- 依赖video-upload模块：使用videoId参数
- 依赖video-player模块：使用视频播放器
- 依赖human-pose-render模块：使用人体姿态渲染
