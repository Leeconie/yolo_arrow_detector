# 视频播放模块

## 模块概述

视频播放模块负责实现视频播放、逐帧控制、图层叠加等核心交互功能。支持视频播放、暂停、进度控制、关键帧跳转等功能。

## 模块职责

- 视频播放控制（播放、暂停、进度控制）
- 逐帧控制
- 关键帧跳转
- 视频信息获取
- 帧数据获取
