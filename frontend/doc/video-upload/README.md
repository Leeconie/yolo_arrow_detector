# 视频上传模块

## 模块概述

视频上传与类型选择模块负责实现视频文件的上传、格式校验、类型选择等功能。支持分片上传、断点续传、上传进度实时展示，以及视频类型（运动人体视频/射箭视频）的选择。

## 🎯 最新修复 (v1.2.0)

### 文件格式过滤问题修复

**问题**: 文件选择器只显示MP4格式，其他格式(AVI、MOV、MKV)不可见

**解决方案**: 实施MIME类型 + 文件扩展名双重保障

```html
accept="video/mp4,video/avi,video/quicktime,video/x-matroska,.mp4,.avi,.mov,.mkv"
```

**兼容性支持**:

- ✅ Chrome/Edge: MIME类型 + 扩展名双重过滤
- ✅ Firefox: 扩展名优先，MIME类型备选
- ✅ Safari: 具体MIME类型列表
- ✅ 移动端: 渐进式增强支持

### 开始分析按钮状态同步修复

**问题**: 视频文件选择成功后，开始分析按钮仍处于禁用状态

**解决方案**: 重构状态管理逻辑，确保UI状态与文件选择状态同步

- 修复 `handleTargetSuccess`/`handlePoseSuccess` 回调
- 确保 `canStartAnalysis` 计算属性正确响应状态变化
- 添加状态调试和错误处理
