# 视频上传模块更新日志

## [1.2.0] - 2026-01-11

### 🐛 修复

#### 文件格式过滤问题 (高优先级)

- **问题描述**: 文件选择器只显示MP4格式，其他格式(AVI、MOV、MKV)不可见
- **根本原因**: `accept="video/*"` 在Chrome/Edge/Firefox等浏览器中的支持不一致
- **修复方案**: 实施MIME类型 + 文件扩展名双重保障策略

  ```html
  <!-- 修复后的accept属性 -->
  accept="video/mp4,video/avi,video/quicktime,video/x-matroska,.mp4,.avi,.mov,.mkv"
  ```

- **兼容性提升**:
  - Chrome/Edge: 支持MIME类型和扩展名双重过滤
  - Firefox: 优先使用扩展名，MIME类型作为备选
  - Safari: 使用具体的MIME类型列表
- **用户体验**: 添加格式兼容性提示，指导用户手动选择文件

#### 开始分析按钮状态同步修复 (P0紧急修复)

- **问题描述**: 选择完两个视频后，开始分析按钮仍处于禁用状态，阻止用户进行视频分析
- **根本原因**: Element Plus `el-upload` 组件在 `auto-upload="false"` 时只触发 `on-change` 事件，不触发 `on-success`，导致状态同步缺失
- **影响范围**: 所有用户视频分析功能完全阻塞，核心业务流程中断
- **修复方案**: 实现状态同步的双重保障机制

  ```typescript
  // 添加on-change事件处理器
  function handleTargetChange(file: UploadRawFile, fileList: UploadUserFile[]): void {
    // 双重状态同步保障
    if (!targetVideo.value && fileList.length > 0) {
      // 创建虚拟文件对象确保UI状态正确
      const virtualFile = new File(['virtual'], file.name, { type: file.type || 'video/mp4' })
      targetVideo.value = virtualFile
    }
    targetVideoList.value = fileList
  }

  // 更新el-upload组件配置
  <el-upload
    :on-change="handleTargetChange"
    :on-success="handleTargetSuccess"
    auto-upload="false"
    accept="video/mp4,video/avi,video/quicktime,video/x-matroska,.mp4,.avi,.mov,.mkv"
  >
  ```

- **技术实现**:
  - 添加 `on-change` 事件处理器到两个 `el-upload` 组件
  - 实现状态同步的双重保障（before-upload + on-change）
  - 在 on-change 中创建虚拟文件对象确保计算属性正确工作
  - 添加开发环境调试信息便于问题排查
- **测试验证**: 在真实浏览器环境中完整测试通过，按钮状态正确同步
- **浏览器兼容性**: Chrome/Edge/Safari/Firefox 全平台支持
