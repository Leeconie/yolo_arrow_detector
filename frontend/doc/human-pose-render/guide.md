# 人体姿态渲染模块开发文档

## 一、模块概述

### 1.1 功能描述

人体姿态渲染模块负责在Canvas上渲染人体关键点、骨架结构、手部关键点等分析结果。支持关键点按置信度显示透明度、骨架显隐切换、手部区域标记等功能。

### 1.2 适用场景

- 人体姿态分析结果可视化
- 手部关键点高亮显示
- 骨架结构展示

### 1.3 技术栈版本

- **fabric.js**: 5.3.0
- **Canvas API**: 原生API

## 二、目录结构

本模块创建的目录和文件：

```text
src/modules/analysis/human-pose/
├── composables/
│   └── useHumanPoseRender.ts   # 人体姿态渲染组合式函数
└── utils/
    └── canvasUtil.ts           # Canvas渲染工具函数
```

## 三、技术实现

### 3.1 关键点绘制

- 使用fabric.js的Circle对象
- radius=4，颜色区分（人体：#409EFF，手部：#F56C6C）
- 透明度=1-置信度

### 3.2 骨架绘制

- 预设关键点连接关系数组
- 使用Line对象绘制，strokeWidth=2
- 显隐切换通过控制visible属性

### 3.3 手部区域标记

- 计算手部关键点的边界
- 生成矩形边框（dashArray虚线样式）

### 3.4 性能优化

- 使用fabric.js的group功能
- 单帧所有对象分组管理
- 重绘时清空分组并重新添加

## 四、接口定义

本模块不直接调用API，数据来源于analysisStore.frameDataList。

## 五、组件说明

本模块不包含Vue组件，主要为工具函数和组合式函数。

## 六、开发要点

1. 关键点坐标需转换为Canvas坐标体系
2. 骨架连接关系需预先定义
3. 性能优化：避免不必要的重绘

## 七、测试要求

- 单元测试：测试关键点绘制、骨架绘制逻辑
- 视觉测试：验证渲染效果正确性

## 八、依赖关系

- 依赖core模块：使用analysisStore、类型定义
- 依赖video-player模块：使用Canvas画布
